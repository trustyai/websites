# V槽 CMS — 可视化内容管理后台

给 vgrooving 这类产品展示站做的一套**前台 + 后台**系统。装好后，你（或你卖给的客户）可以在网页后台里：

- 📦 **管理产品**：上传图片 / 视频、改标题、改标签、改描述、排序、增删
- ✏️ **改文案**：品牌名、Logo、首页大标题、数据指标、核心优势、联系方式、页脚
- 💬 **配置客服**：欢迎语、快捷问题、关键词自动回复
- 🎨 **一键换风格**：内置 **6 套主题**，点一下整站换皮肤，不用碰代码
- 🔐 **密码登录**：后台有账号密码保护，可自行修改密码

前台完全按 vgrooving.com 的视觉风格复刻：深色英雄区 + 智能选型向导 + 产品卡片 + 在线客服气泡。全程在浏览器里操作，**不用再去改前端代码**。

---

## 一、本地运行

需要先装 [Node.js](https://nodejs.org)（18 以上版本）。

```bash
cd vgrooving-cms
npm install
npm start
```

启动后：

```
前台：  http://localhost:3000
后台：  http://localhost:3000/admin
默认账号： admin   密码： admin123
```

打开 **http://localhost:3000/admin** 登录即可。
**第一次登录后，请到「账号安全」里改掉默认密码。**

> 想换端口：`PORT=8080 npm start`

---

## 二、后台怎么用

左侧 7 个菜单：

| 菜单 | 能做什么 |
|------|----------|
| 🎨 品牌与主题 | 改品牌名、上传 Logo、编辑导航菜单、**切换 6 套主题风格** |
| 🏠 首页文案 | 改首屏大标题、副标题、按钮、4 个数据指标 |
| ⭐ 核心优势 | 「为什么选择我们」的卖点（增删改、排序） |
| 📦 产品管理 | 上传产品图片/视频、改标题标签描述、上下排序、增删 |
| 📞 联系与页脚 | 行动号召、电话/邮箱/微信、版权信息 |
| 💬 在线客服 | 客服名、欢迎语、快捷问题、关键词自动回复 |
| 🔒 账号安全 | 修改登录密码 |

改完点右上角 **「保存全部修改」**（或按 Ctrl/Cmd + S），前台刷新即可看到更新。

> **大标题小技巧**：标题里**第一个空格之后**的文字会自动高亮并换行。
> 例如填「找到最适合 你的开槽机」，前台会把"你的开槽机"用主题色强调并换行。

**智能选型**：前台向导按产品的「选型匹配」标签推荐设备。在产品管理里给每个产品填上匹配标签即可：
厚度 `thin`(薄) / `medium`(中) / `thick`(厚) / `custom`(超厚)，规模 `small` / `large`。

**上传说明**：单个文件最大 300MB，视频支持 mp4 / webm / mov；图片支持 jpg / png / gif / webp / svg。上传的文件都存在 `public/uploads/` 里。

## 三、6 套主题

| 主题 | 风格 | 适合 |
|------|------|------|
| 品牌·翠绿 | 清爽绿意、专业稳重（默认，贴合当前站点） | vgrooving 现有风格 |
| 工业·橙黑 | 深色硬朗、力量感 | 机械 / 制造业 |
| 科技·深蓝 | 深蓝霓虹、玻璃质感 | 智能 / 数控 / 高端设备 |
| 极简·留白 | 黑白克制、杂志编排 | 精品工作室 / 高端定位 |
| 优雅·墨绿 | 米色衬线、沉稳高级 | 传统出口 / 品牌叙事 |
| 活力·热橙 | 明快圆润、有冲击力 | 电商 / 快消导向 |

在后台「品牌与主题」里点一下就能换，**这样卖给不同客户时，每家长得都不一样。**

### 想加新主题？
打开 `public/themes/themes.js`，复制任意一套，改个 key、改改颜色和字体即可，后台会自动出现新选项。每套主题就是一组 CSS 变量（颜色、圆角、阴影、字体），不用动其它代码。

## 四、部署到服务器

这是一个 Node 程序，需要一台能跑 Node 的服务器（不能放在纯静态托管上）。

### 方式 A：宝塔面板（适合新手）
1. 服务器装好「宝塔面板」，在软件商店装 **Node.js 版本管理器**（选 18+）和 **PM2 管理器**。
2. 把整个 `vgrooving-cms` 文件夹上传到服务器（如 `/www/vgrooving-cms`）。
3. 在该目录执行一次 `npm install`。
4. 用 PM2 管理器添加项目，启动文件选 `server.js`，端口 `3000`。
5. 在「网站」里给你的域名做**反向代理**到 `http://127.0.0.1:3000`，并开启 SSL（https）。

### 方式 B：命令行 + PM2
```bash
npm install -g pm2
cd vgrooving-cms && npm install
pm2 start server.js --name vgrooving
pm2 save && pm2 startup
```
再用 Nginx 把域名反代到 `127.0.0.1:3000`（记得配 https）。

## 五、卖给别人时的准备

1. **改默认内容**：编辑 `data/content.default.json`（首次启动会用它生成数据），换成空模板或对应客户的资料。
2. **删掉旧数据**：交付前删除 `data/content.json`、`data/config.json` 和 `public/uploads/` 里的文件，让客户首次启动时是干净状态、用默认账号密码。
3. **加主题**：按上面第三节加几套风格，卖点更足。
4. （可选）改后台 Logo 文字、登录页标题：在 `admin/index.html` 里搜索"V槽 CMS"替换。

---

## 六、数据与备份

- 所有内容都存在 **`data/content.json`**（一个 JSON 文件，无需数据库）。
- 上传的图片/视频在 **`public/uploads/`**。
- 备份只需复制 `data/` 和 `public/uploads/` 两个文件夹即可。
- 账号密码（加密后）存在 `data/config.json`，**忘记密码**时删掉它会重置回 admin / admin123。

## 七、目录结构

```
vgrooving-cms/
├── server.js              # 后端服务（认证 / 内容API / 上传）
├── package.json
├── data/
│   ├── content.default.json   # 默认内容模板
│   ├── content.json           # 实际内容（首次启动生成，可备份）
│   └── config.json            # 账号密码（首次启动生成）
├── public/                # 前台
│   ├── index.html
│   ├── styles.css
│   ├── app.js             # 前台渲染
│   ├── assets/logo.png
│   ├── themes/themes.js   # ★ 6 套主题定义（前后台共用）
│   └── uploads/           # 上传的图片/视频
└── admin/                 # 后台
    ├── index.html
    └── admin.js
```
