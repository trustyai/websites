# V槽 CMS — 多语言可视化内容管理后台

vgrooving.com 的**前台 + 后台**系统。前台按原站视觉 1:1 复刻，后台可视化编辑，**六种语言全部在后台管理，所有页面都能改，无需碰代码**。

## 功能

- 🌍 **六语言**：中文 / English / Español / 한국어 / العربية(自动 RTL) / Türkçe，前台带语言切换，后台按语言编辑
- 🏠 **首页**：英雄区文案与数据指标、智能选型向导（材料/厚度/产量/功能四步，按产品匹配推荐）
- 📦 **产品详情页**：图集（图片/视频+灯箱）、价格、交付标签、信任徽章、核心优势、亮点、技术参数、相关推荐
- 📞 **联系页**：联系方式、全球经销商/代理商、代理招募、询价表单
- 💬 **在线客服**：欢迎语、快捷问题、关键词自动回复（分语言）
- 🔐 **密码登录**：后台账号密码保护，可自行修改

数据存 JSON 文件，无需数据库。

## 本地运行

需要 [Node.js](https://nodejs.org) 18+。

```bash
cd vgrooving-cms
npm install
npm start
```

```
前台：  http://localhost:3000
后台：  http://localhost:3000/admin
默认账号： admin   密码： admin123
```

首次登录后请到「账号安全」修改默认密码。

## 前台网址结构

| 页面 | 中文(默认) | 其它语言(以英文为例) |
|------|-----------|---------------------|
| 首页 | `/` | `/en` |
| 产品详情 | `/products/manual` | `/en/products/manual` |
| 联系页 | `/contact` | `/en/contact` |

旧链接（`/products/xxx.html`、`/en/contact.html`、`/en/index.html` 等）都会自动兼容；其它未知地址会跳回首页，避免 404。

## 后台怎么用

顶部有**语言切换**（中/英/西/韩/阿/土），选中哪个语言，下面编辑的就是那个语言的内容。左侧菜单：

| 菜单 | 能改什么 |
|------|----------|
| 🎨 品牌与导航 | 全局 Logo、默认语言、语言列表；各语言品牌名、导航菜单、按钮文字 |
| 🏠 首页文案 | 英雄区标题/副标题/按钮、数据指标、页面标题(SEO) |
| 🧭 智能选型 | 向导文案 + 材料/厚度/产量/功能四步的所有选项 |
| 📦 产品管理 | 每个产品：徽章、名称、副标题、卡片、价格、交付、信任徽章、优势、亮点、参数、相关、图集(可上传图片/视频)、选型匹配 |
| 📞 联系页 | 联系方式、全球经销商、代理招募、询价表单 |
| 💬 在线客服 | 客服信息、欢迎语、兜底回复、快捷问题、关键词回复 |
| 📥 收件箱 | 前台询价留言列表、已读/删除、导出 CSV |
| 🖼️ 媒体库 | 浏览所有已上传图片/视频，复制链接、删除；产品处可「从媒体库选择」复用 |
| 🧰 翻译与备份 | 添加新语言、语言间复制、导出/导入内容备份；**站点设置**(网址/通知 Webhook/统计代码/SMTP 邮件) |
| 📊 仪表盘 | 语言/产品/媒体/未读询价统计、**访问量趋势**、热门页面、各语言完成度 |
| 🔒 账号安全 | 修改登录密码 |

**批量与营销能力：**
- 📦 **产品批量导入/导出 Excel**（产品管理页）：导出为 xlsx（每语言一个工作表），编辑后导入按 slug/id 更新，适合大批量改文案/翻译。
- 🔍 **前台搜索**：导航栏放大镜可搜产品名/描述/标签/参数。
- 📈 **访问统计**：内置轻量统计（无需第三方）；也可在「站点设置 → 统计代码」粘贴 Google Analytics / 百度统计代码。
- 📬 **询价通知**：新询价可同时（a）存入后台收件箱、（b）推送到企业微信/钉钉/飞书群机器人、（c）发送到指定邮箱（SMTP）。
- 🔎 **SEO**：服务端注入标题/描述/OG/多语言 hreflang，提供 `/sitemap.xml` 与 `/robots.txt`。

**省时技巧**：
- 右上角「🔎 预览」按当前语言打开前台。
- 产品卡片右上角「🔁」可把图集/封面/价格一键同步到所有语言（图片和价格通常各语言相同）。
- 「翻译与备份 → 添加新语言」会用模板语言的内容作为起点，避免从零开始。

改完点右上角 **「保存全部修改」**（或 Ctrl/Cmd + S），前台刷新即生效。

> **标题高亮**：大标题里用 `*星号*` 包住的文字会用主题色高亮，回车换行。例：`找到*最适合*` 换行 `你的*开槽机*`。
>
> **智能选型匹配**：给每个产品填「选型匹配」标签即可参与推荐。厚度 `thin`/`medium`/`thick`/`custom`，规模 `small`/`large`。
>
> **上传**：单文件最大 300MB，视频 mp4/webm/mov，图片 jpg/png/gif/webp/svg，存于 `public/uploads/`。

## 部署（宝塔）

1. 软件商店装 **Node 版本管理器**(18+) 与 **PM2 管理器**。
2. 上传 `vgrooving-cms` 到服务器（如 `/www/vgrooving-cms`），进目录执行 `npm install`。
3. PM2 添加项目，启动文件 `server.js`。程序监听 3000 端口。
4. 站点「反向代理」到 `http://127.0.0.1:3000`，并在配置里加 `client_max_body_size 300m;`（否则大视频上传会 413）。
5. 开启 SSL。

## 数据与备份

- 内容全部在 `data/content.json`（多语言 JSON）。
- 账号密码（加密）在 `data/config.json`，忘记密码删掉它会重置为 admin/admin123。
- 上传文件在 `public/uploads/`。
- 备份只需复制 `data/` 和 `public/uploads/`。
- 交付新客户前：删除 `data/content.json`、`data/config.json` 与 `public/uploads/` 内文件，首次启动会用 `data/content.default.json` 生成干净数据。

## 目录结构

```
vgrooving-cms/
├── server.js              # 后端：鉴权 / 内容API / 上传 / 多语言路由
├── package.json
├── data/
│   ├── content.default.json   # 默认内容（六语言模板）
│   ├── content.json           # 实际内容（首次启动生成）
│   └── config.json            # 账号密码（首次启动生成）
├── public/
│   ├── index.html / product.html / contact.html   # 三种页面外壳
│   ├── common.js          # 公共逻辑：语言检测/导航/语言切换/客服
│   ├── app.js             # 首页渲染
│   ├── product.js         # 产品详情渲染
│   ├── contact.js         # 联系页渲染
│   ├── styles.css         # 原站真实样式
│   ├── assets/logo.png
│   └── uploads/
└── admin/                 # 后台
    ├── index.html
    └── admin.js
```
