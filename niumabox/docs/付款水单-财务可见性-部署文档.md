# Niumabox · 财务模块优化（第二批：付款水单 + 财务可见性）部署文档

让业务员在**客户卡**上传付款水单（图片/PDF → 阿里云 OSS），入库后**自动邮件通知团队财务**；同时补齐财务角色前端可见性（第一批 RLS 已放行，但列表之前仍按本人过滤）。

## 1. 阿里云 OSS 准备（一次）

已确认 bucket：**niumabox**，区域 **华南1·深圳 `oss-cn-shenzhen`**。

1. 建 RAM 子用户，只给该 bucket 的 `oss:PutObject`（建议前缀 `payment-proofs/`）。
2. 创建 AccessKey，后面写进 `.env`（**不要**放前端）。
3. **CORS**（控制台 → bucket → 数据安全 → 跨域设置）加一条：
   - 来源：`https://niumabox.com`（可再加 `http://localhost` 方便自测）
   - Methods：`GET, POST, HEAD`
   - Headers：`*`
   - Expose Headers：`ETag, x-oss-request-id`
4. **读权限**：水单链接要能被财务邮箱里直接打开。二选一：
   - 推荐简单：给前缀 `payment-proofs/` 公共读（bucket 策略只放行该前缀 GetObject）；或
   - 整桶公共读（不推荐）。

## 2. 后端 `.env` 追加

在 `/www/wwwroot/niumabox-api/.env` 加：

```ini
# --- 付款水单 OSS ---
OSS_ACCESS_KEY_ID=你的RAM_AK
OSS_ACCESS_KEY_SECRET=你的RAM_SK
OSS_BUCKET=niumabox
OSS_REGION=oss-cn-shenzhen
OSS_DIR=payment-proofs
OSS_MAX_SIZE_MB=10
# 可选；默认 https://niumabox.oss-cn-shenzhen.aliyuncs.com
# OSS_PUBLIC_BASE=https://niumabox.oss-cn-shenzhen.aliyuncs.com

# --- 水单通知 webhook 密钥(自己编一长串;SQL 触发器里要写成同一串) ---
FINANCE_WEBHOOK_SECRET=换成你自己的一长串随机字符
```

SMTP / SUPABASE_* 沿用询盘通知已有配置即可。

## 3. 挂路由 + 重启

1. 上传三个 backend 文件到 `src/`（`routes-finance.js` → `src/routes/finance.js`）。
2. 在 `src/index.js` 其它 `app.use('/api/...')` 旁加一行：

```js
app.use('/api/finance', require('./routes/finance'));
```

3. 重启：

```bash
pm2 restart niumabox-api --update-env
pm2 logs niumabox-api --lines 40
```

4. 冒烟（把 JWT 换成真实登录 token；或先测 webhook）：

```bash
# 签名接口(需登录 JWT)
curl -s -X POST http://127.0.0.1:3100/api/finance/oss-sign \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer 你的JWT' \
  -d '{"fileName":"test.pdf","contentType":"application/pdf"}'
# 期望 ok:true + host/key/policy/signature

# 通知接口(用 webhook secret)
curl -s -X POST http://127.0.0.1:3100/api/finance/notify-proof \
  -H 'Content-Type: application/json' \
  -H 'x-webhook-secret: 你的FINANCE_WEBHOOK_SECRET' \
  -d '{"record":{"id":"00000000-0000-0000-0000-000000000001","owner_id":"某业务员uuid","customer_id":null,"user_id":"某业务员uuid","amount":100,"currency":"USD","note":"test","file_name":"t.pdf","file_url":"https://example.com/t.pdf","created_at":"2026-07-20T00:00:00Z"}}'
```

## 8. 设计说明

- **文件**：浏览器直传 OSS（PostObject + 后端 HMAC 签名），API 不扛文件流。
- **元数据**：`payment_proofs`；`owner_id` = 客户归属业务员，供 `fn_finance_of(owner_id)` 团队可见。
- **通知**：INSERT 触发器 `notify_new_payment_proof` → `pg_net` POST `/api/finance/notify-proof` → 查该业务员团队里 `role=finance` 成员邮箱 → nodemailer。
- **权限**：财务/老板可读；上传人/归属人/老板可删记录（OSS 文件不自动删，避免误伤）。

## 9. 常见坑

| 现象 | 原因 |
|---|---|
| 上传 CORS 失败 | bucket 未加 `niumabox.com` 跨域 |
| 邮件打不开文件 | 前缀未公共读 / URL 拼错 |
| 上传成功但财务没信 | SQL 里 secret 与 `.env` 不一致；或团队没设 finance；看 `pm2 logs` |
| 财务看不到团队单据 | `/api/team` 没返回 `role:'finance'`；或未跑 `05-finance-role.sql` |
| `OSS_NOT_CONFIGURED` | `.env` 缺 AK/SK，或重启时没 `--update-env` |
